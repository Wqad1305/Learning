\-----------------------------------------------------------------------------------------------------------------------

Key/Value	|  Key → Value	                  |      Rất nhanh	            |     Cache, Session

Column Family	|  Dữ liệu theo cột/partition	  |      Dữ liệu lớn, scale tốt	    |     IoT, Log

Graph	        |  Node → Relationship → Node	  |      Mạnh về quan hệ	    |     Mạng xã hội, Recommendation

Document	|  JSON/BSON Document	          |      Linh hoạt	            |     Website, E-commerce



1. Key/Value: Redis → truy cập bằng Key.
2. Column Family: Cassandra → mạnh về dữ liệu lớn + nhiều server.
3. Graph: Neo4j → mạnh về mối quan hệ.
4. Document: MongoDB → mạnh về JSON + schema linh hoạt.
5. SQL Server: mạnh về Table + JOIN + Transaction.

\--------------------------------------------------------------------------------------------------------------------------------------

1\. Key/Value Store – Redis

* Đặc điểm, ưu/nhược: Lưu Key → Value; ưu điểm rất nhanh, đơn giản; nhược điểm khó xử lý quan hệ phức tạp.
* So với SQL Server: Redis truy xuất Key nhanh và linh hoạt hơn; SQL Server mạnh về bảng, JOIN và Transaction.
* Ứng dụng: Cache, Session, giỏ hàng, Realtime.
* Doanh nghiệp sử dụng: Tăng tốc hệ thống và giảm tải database chính.
* Cài đặt/phần cứng: Windows/Linux/Docker/Cloud; cần chú ý RAM.

2\. Column Family Store – Cassandra

* Đặc điểm, ưu/nhược: Lưu dữ liệu theo Column/Partition; ưu điểm xử lý dữ liệu lớn, mở rộng tốt; nhược điểm JOIN yếu.
* So với SQL Server: Cassandra mạnh về dữ liệu phân tán và Scale-out; SQL Server mạnh về quan hệ và Transaction.
* Ứng dụng: IoT, Log, Big Data, dữ liệu cảm biến.
* Doanh nghiệp sử dụng: Xử lý dữ liệu lớn trên nhiều server và đảm bảo tính sẵn sàng.
* Cài đặt/phần cứng: Linux/Docker/Cloud; cần chú ý RAM, SSD, Network.

3\. Graph Store – Neo4j

* Đặc điểm, ưu/nhược: Lưu Node + Relationship; ưu điểm xử lý quan hệ rất tốt; nhược điểm không phù hợp dữ liệu bảng thông thường.
* So với SQL Server: Neo4j mạnh về quan hệ và đường đi; SQL Server mạnh về bảng và JOIN.
* Ứng dụng: Mạng xã hội, Recommendation, phát hiện gian lận.
* Doanh nghiệp sử dụng: Phân tích và tìm kiếm các mối quan hệ giữa dữ liệu.
* Cài đặt/phần cứng: Windows/Linux/Docker/Cloud; chú ý RAM, SSD.

4\. Document Store – MongoDB

* Đặc điểm, ưu/nhược: Lưu dữ liệu dạng Document JSON/BSON; ưu điểm linh hoạt, dễ thay đổi; nhược điểm JOIN yếu hơn SQL.
* So với SQL Server: MongoDB linh hoạt về cấu trúc dữ liệu; SQL Server mạnh về quan hệ và Transaction.
* Ứng dụng: Website, E-commerce, Mobile App, CMS.
* Doanh nghiệp sử dụng: Phát triển ứng dụng nhanh và dễ thay đổi dữ liệu.
* Cài đặt/phần cứng: Windows/Linux/Docker/Cloud; chú ý RAM, SSD.





=>Redis = Key → Value | Cassandra = Cột | Neo4j = Quan hệ | MongoDB = Document/JSON | SQL Server = Bảng.
