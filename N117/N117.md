Cassandra – NoSQL



1\. Cassandra là gì?



* Cassandra là hệ quản trị CSDL NoSQL dạng Column-Family, được thiết kế để lưu trữ lượng dữ liệu rất lớn và xử lý nhiều truy cập đồng thời.



2\. Đặc điểm chính



* Phân tán: dữ liệu được lưu trên nhiều máy.



* Không có máy chủ trung tâm → giảm điểm lỗi đơn.



* Mở rộng ngang: thêm máy → tăng khả năng xử lý.



* High Availability: hệ thống vẫn hoạt động khi một số node gặp lỗi.



* Dữ liệu tổ chức theo Keyspace → Table → Row → Column.



3\. Khi nào dùng?



* Dữ liệu rất lớn.



* Cần tốc độ ghi/đọc cao.



* Hệ thống cần hoạt động liên tục.



4\. Cú pháp



CREATE KEYSPACE Shop



WITH replication = {

&#x20; 'class': 'SimpleStrategy',

&#x20; 'replication\_factor': 3

};



USE Shop;



CREATE TABLE SanPham (

&#x20;   id INT PRIMARY KEY,

&#x20;   ten TEXT,

&#x20;   gia DECIMAL

);



INSERT INTO SanPham (id, ten, gia)

VALUES (1, 'iPhone', 20000000);



SELECT \* FROM SanPham;



* Cassandra = NoSQL Column-Family + phân tán + mở rộng ngang + dữ liệu lớn + tốc độ cao.

Linear



1\. Linear là gì?



* Linear thường chỉ mô hình tuyến tính, trong Machine Learning phổ biến nhất là Linear Regression – dùng để dự đoán giá trị số.



2\. Đặc điểm chính



* Dự đoán giá trị liên tục.



* Dựa trên mối quan hệ tuyến tính giữa X và y.



* Công thức: y = ax + b.



* Dễ hiểu, dễ triển khai



3\. Khi nào dùng?



* Dự đoán giá nhà.



* Dự đoán doanh thu.



* Dự đoán điểm số.



* Dự đoán các giá trị dạng số.



4\. Python cơ bản



from sklearn.linear\_model import LinearRegressionmodel = LinearRegression()model.fit(X\_train, y\_train)y\_pred = model.predict(X\_test)





* Linear Regression = hồi quy tuyến tính → dự đoán số → LinearRegression() → fit() → predict().
