1. Tạo và quản lý cơ sở dữ liệu
* Tạo database
* Chọn database để làm việc (USE)

2\. Tạo bảng và cấu trúc dữ liệu

* Tạo bảng (CREATE TABLE)
* Khóa chính (PRIMARY KEY)
* Kiểu dữ liệu (INT, NVARCHAR, FLOAT)
* Tự tăng (IDENTITY)

3\. Viết hàm trong SQL

* Hàm tính toán (cộng, thành tiền, giảm giá)
* Trả về giá trị (RETURNS)

4\. Truy vấn và sử dụng hàm

* SELECT
* Gọi hàm trực tiếp trong SQL

5\. Duyệt dữ liệu bằng con trỏ (CURSOR)

* Đọc từng dòng trong bảng
* FETCH, WHILE, PRINT

6.Xử lý điều kiện từng dòng

* Câu lệnh điều kiện
* IF...ELSE
* Kiểm tra tồn kho, giá sản phẩm

7\. Sao lưu và khôi phục dữ liệu

* BACKUP DATABASE
* RESTORE DATABASE
