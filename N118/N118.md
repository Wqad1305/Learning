CƠ SỞ DỮ LIỆU REDIS



5.1. Tổng quan về Redis



* Redis là hệ quản trị cơ sở dữ liệu NoSQL dạng Key-Value.



* Dữ liệu chủ yếu được lưu trong RAM nên tốc độ đọc/ghi rất nhanh.



* Thường dùng để cache, lưu session, bảng xếp hạng, đếm lượt truy cập.



* Redis hỗ trợ nhiều kiểu dữ liệu: String, List, Set, Hash, Sorted Set.

5.2. Cài đặt và cấu hình Redis



* Cài Redis trên máy và khởi động Redis Server.



* Sử dụng Redis CLI hoặc công cụ quản lý Redis để thao tác.



* Kiểm tra kết nối

→ Nếu trả về PONG là Redis hoạt động.



5.3. Cấu trúc dữ liệu trên Redis



1\. String → lưu chuỗi, số.

SET ten "Hoang"

GET ten



2\. List → danh sách, có thứ tự.

LPUSH sanpham "Iphone"

LRANGE sanpham 0 -1



3\. Set → tập hợp không trùng.

SADD monan "Pizza"

SMEMBERS monan



4\. Hash → lưu dạng thuộc tính–giá trị, giống một object.

HSET user:1 ten "Hoang" tuoi 20

HGETALL user:1



5\. Sorted Set → tập hợp có điểm số để sắp xếp.

ZADD ranking 100 "Hoang"

ZRANGE ranking 0 -1



5.4. Các lệnh thao tác Database trên Redis



* SET → thêm/cập nhật dữ liệu.



* GET → lấy dữ liệu.



* DEL → xóa dữ liệu.



* EXISTS → kiểm tra key tồn tại.



* KEYS \* → xem các key.



* TYPE → xem kiểu dữ liệu.



* EXPIRE → đặt thời gian hết hạn.



* TTL → xem thời gian còn lại.



* FLUSHDB → xóa toàn bộ dữ liệu database hiện tại.



* DBSIZE → đếm số key.



\-> SET/GET → String | LPUSH/LRANGE → List | SADD/SMEMBERS → Set | HSET/HGETALL → Hash | ZADD/ZRANGE → Sorted Set.

INTERMEDIATE PYTHON



1\. Basic plots with Matplotlib



* Matplotlib là thư viện dùng để vẽ và trực quan hóa dữ liệu.



* Import:

import matplotlib.pyplot as plt



* Các biểu đồ chính:



* &#x20; plot() → biểu đồ đường.



* &#x20; scatter() → biểu đồ phân tán.



* &#x20; bar() → biểu đồ cột.



* &#x20; hist() → biểu đồ tần suất.





* Một số lệnh:



* &#x20; xlabel() → tên trục X.



* &#x20; ylabel() → tên trục Y.



* &#x20; title() → tiêu đề.



* &#x20; show() → hiển thị biểu đồ.



2\. Pandas



* Pandas là thư viện dùng để đọc, xử lý và phân tích dữ liệu.
* Import:

import pandas as pd



1. Cấu trúc dữ liệu:



* &#x20; Series → dữ liệu 1 chiều.



* &#x20; DataFrame → dữ liệu dạng bảng 2 chiều.



2\. Các lệnh thường dùng:



* &#x20; read\_csv() → đọc file CSV.



* &#x20; read\_excel() → đọc file Excel.



* &#x20; head() → xem dữ liệu đầu.



* &#x20; info() → xem thông tin dữ liệu.



* &#x20; describe() → thống kê dữ liệu.



* &#x20; shape → xem số dòng, cột.



* &#x20; sort\_values() → sắp xếp dữ liệu.



* &#x20; drop() → xóa dữ liệu.



* &#x20; loc\[], iloc\[] → truy xuất dữ liệu.



\->Matplotlib → vẽ biểu đồ | Pandas → đọc + xử lý + phân tích dữ liệu
