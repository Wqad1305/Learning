Linear Classifiers in Python



1\. Logistic Regression

* Phân loại.
* predict() → dự đoán lớp.
* predict\_proba() → xác suất.
* C → regularization.



2\. Logistic Regression đa lớp

* OVR → 1 lớp vs phần còn lại.
* Softmax → phân loại nhiều lớp trực tiếp.



3\. SVM

* Tìm đường biên phân loại.
* Support vector → điểm gần đường biên.
* SVC(kernel="linear") → SVM tuyến tính.
* SVC() → RBF SVM.



4\. Tham số \& tối ưu

* C → regularization của Logistic/SVM.
* gamma → ảnh hưởng của điểm trong RBF SVM.
* GridSearchCV → tìm tham số tốt nhất.
* best\_params\_ → tham số tốt nhất.
* best\_score\_ → điểm CV tốt nhất.



5\. SGDClassifier

* loss='hinge' → gần SVM.
* loss='log\_loss' → gần Logistic Regression.
* alpha → regularization.
